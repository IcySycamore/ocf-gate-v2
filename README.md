# ocf-gate-v2

人机协作门控状态机的重写版本。目标是用可测试的核心替换难以维护的旧实现：
状态迁移由**纯函数**裁决，事实由**声明式规则**校验，文件只负责持久化。

> 状态：早期开发中。目前完成事实层（受理 / 计划）与校验，状态迁移仍是旧代码。

## 结构

```
state_machine/
  abstract_fact.py   事实基类：读入 / 校验 / 重置（机制）
  intake_gate.py     受理期事实   IntakeFact（形状 + 规则）
  plan_gate.py       计划期事实   PlanFact（形状 + 规则）
  base_gate.py       状态、批准令牌与迁移表（待重构）
tests/               标准库 unittest，无第三方依赖
docs/facts.md        事实分组、寿命与清理时机
```

## 设计要点

- **字段与规则分离**：字段是形状，必填项是策略。策略写在 `RULES` 里，改它不动类定义。
- **两种失败分开**：程序写错（规则与字段对不上）抛异常；人类还没说清楚（必填项为空）返回 `(False, 字段名)`。混在一起会让配置漂移永远查不出来。
- **事实文件是 `key=value`**：受理是边问边记的，只能增量写；顺序无关、可追加。
- **默认值承担三个职责**：构造默认值、重置目标、读入时的类型依据。因此每个字段都必须有默认值。

细节见 [docs/facts.md](docs/facts.md)。

## 运行

```bash
python -m unittest discover -s tests -v
```

无需安装依赖，只用标准库。
